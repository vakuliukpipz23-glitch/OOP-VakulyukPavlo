Лабораторна робота №28
Тема: Серіалізація об’єктів у JSON
Мета роботи

Навчитися серіалізувати та десеріалізувати складні об’єкти у форматі JSON, а також зберігати дані у файли та завантажувати їх у консольному застосунку C#.

Завдання
Створити консольний проєкт lab28v1.
Реалізувати класи предметної області (бібліотека): Book, Author, BookRepository.
Реалізувати репозиторій з методами:
SaveToFileAsync(string filename)
LoadFromFileAsync(string filename)
Add(Book book)
GetAll()
GetById(int id)
Продемонструвати роботу в методі Main: створення об’єктів, збереження у JSON файл, завантаження з файлу, вивід результату.
Опис предметної області

Предметна область — бібліотека.
Система дозволяє зберігати інформацію про книги та їх авторів.

Книга має такі властивості:

Id
Title
Year
Author (об’єкт класу Author)

Автор має такі властивості:

Id
FullName
Опис класів
Book

Клас Book представляє книгу в бібліотеці та містить основні дані про книгу, включаючи вкладений об’єкт Author.

Author

Клас Author описує автора книги та містить ідентифікатор та повне ім’я.

BookRepository

Клас BookRepository відповідає за управління колекцією книг та реалізує:

додавання книг
отримання всіх книг
пошук книги за Id
збереження даних у JSON файл
завантаження даних із JSON файлу
Реалізований функціонал

У програмі реалізовано:

створення об’єктів книг та авторів
додавання об’єктів у репозиторій
серіалізація списку книг у JSON файл
десеріалізація даних із JSON файлу
асинхронна робота з файлами
пошук книги за Id
Хід роботи програми
Створюються об’єкти Author і Book.
Книги додаються в BookRepository.
Дані зберігаються у файл books.json.
Створюється новий репозиторій.
Дані завантажуються з файлу.
Виводиться список книг у консоль.
Виконується пошук книги за Id.
Приклад роботи програми

Дані збережено у JSON файл.

Завантажені книги:
1: Clean Code (2008) - Robert Martin
2: The Pragmatic Programmer (1999) - Andrew Hunt

Висновок

У ході лабораторної роботи було створено консольний застосунок на C#, який демонструє роботу з JSON-серіалізацією.
Отримано навички роботи з System.Text.Json, реалізації репозиторію, використання async/await та структурування проєкту.
